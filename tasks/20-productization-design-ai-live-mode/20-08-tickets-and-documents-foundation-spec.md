# 20-08 — Tickets And Documents Foundation Spec

**Estimate:** 1 hour

## Goal

Specify the structured ticket/document layer before implementing Wallet or native
features.

## Scope

- Ticket metadata.
- Booking metadata.
- Confirmation codes.
- Official links.
- Uploaded or linked document constraints.
- Privacy rules for shared/public trips.

## Acceptance Criteria

- Public sharing does not expose private ticket/document data by default.
- Required schema/type changes are identified.
- Wallet is not included in this implementation spec.
- Follow-up implementation tasks are listed.
