# 20-09 — Wallet Feasibility And Platform Decision

**Estimate:** 1 hour

## Goal

Decide whether and when real Wallet integration belongs in the product roadmap.

## Scope

- iOS `.pkpass` requirements.
- Apple Developer Program requirement.
- Server-side pass signing certificate requirement.
- PWA limitations.
- MVP alternatives: structured documents, external links, reminders, exports.

## Acceptance Criteria

- Wallet is not described as a simple frontend feature.
- Required paid/platform dependencies are explicit.
- Decision is recorded as implement now, defer, or reject.
- If deferred, the fallback MVP is documented.
