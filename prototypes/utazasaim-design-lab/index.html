Utazasaim Design Lab

Design system prototype, mobil workflow es screen pattern gyujtemeny.

Prototype: sunset orange, travel accents, iOS jellegu mobil UI

Mire valo ez a mappa?

Ez a statikus lab segit gyorsan donteni a vizualis iranyrol, mielott React komponensekre bontjuk. A design-system oldal adja a token es komponens referenciat, a screenek pedig a valos utazastervezo flowt mutatjak.

Kovetkezo fejlesztesi fokusz

  • Magyar termekszoveg teljes screen szinten.
  • Trip detail, napi program es AI itinerary editor screen.
  • React/Tailwind token megfeleltetes a production apphoz.
